# 在 Obsidian 中使用字根表

1. 把“潇明字根总表.md”放进你的 Obsidian 仓库。
2. 打开 Obsidian 的“设置 → 外观 → CSS 代码片段”，点击文件夹图标。
3. 把“xiaoming-roots.css”复制进打开的代码片段文件夹。
4. 返回设置，刷新代码片段列表，启用“xiaoming-roots”。
5. 打开字根表，切换到阅读视图即可查看。

397 个字根中有 137 个使用专用字符。附带的 CSS 已内嵌所需字体，启用后不需要联网，也不需要在系统中安装字体。

样式仅作用于带有 `xiaoming-root-table` 类的笔记。字根表开头的 `cssclasses` 属性已经配置好，请保留。

阅读视图和实时预览已配置字体；纯源码模式下的表格仍按 Markdown 文本显示。更换设备或仓库时，请同时带上代码片段并在该仓库启用。

文字版保留原始字根字符，不用相似字符替换；按 A、B、C、G、H、L、M、N、O、P、Q、R、S、T、U、V、W、X、Y 分组，每根最多保留与图片相同的两个例字。没有例字的位置记为“—”。

代码片段的使用方法参见 [Obsidian 官方说明](https://obsidian.md/help/snippets)。
