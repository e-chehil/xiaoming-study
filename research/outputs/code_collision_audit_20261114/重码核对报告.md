# 潇明习字简中课程重码核对

补充核对：官网所报 4.108% 是按词频加权的动态词重，已精确复现；本文的 11.32% 是静态词重。同一份官网测评词表静态词重为 12.82%，涉及重码的全部词占 23.37%。详见 [官网词重口径核对](官网词重口径核对.md)，这几项指标不能直接混用。

统计日期：2026-11-14。读取公开网站当前 `learning-runtime.json`，SHA-256 与网站 manifest 一致，也与本地发布包逐字节一致。原方案采用网站清单指定的固定提交 `55e783c3973b125d3f56baac534b796c76df87a5`，原始全码与组合码表已与 GitHub 对应文件逐字节核对。

## 统计口径

课程词语共 53,699 条，其中 22 条含字母或标点，网站未提供可练编码；可编码记录 53,677 条。合并同词同码的不同读音等重复记录 131 条后，得到 **53,546 个不同词形**。以下重码率均以此为分母。比较完整小写编码完全相同，不将前缀相同算作重码；不包含字根课或声母、首笔映射课。全部可编码词语已按共享字根数据独立重算，一致。

## 词语与原方案单字

对照原方案全部 11,177 个单字：**1,270 个词语（2.37%）**与单字全码重合，涉及 **1,050 个编码、1,064 个单字**，共 1,287 对词—字组合。把原方案简码一并加入，冲突数量不变。原因是课程词码均为四码或五码，而原方案简码短于四码。

例如：`ckgi` 女子／长子 ↔ 好；`akttj` 中心／忠心 ↔ 忠；`uebum` 组织／编织 ↔ 练；`wjupf` 伟大 ↔ 侠。完整列表见“词与单字重码.tsv”。

原方案字集包含简体、繁体及生僻字，并非只对照课程中的 5,069 个单字。如果仅对照课程单字，则是 658 个词语、530 个编码；两者范围不同。

## 词语彼此之间

**5,028 个编码**被多个不同词语共享，涉及 **11,089 个词语（20.71%）**。若每组仅保留一个词不算重码，则多出来 **6,061 个词（11.32%）**。后者是“每码保留一项”的静态重码口径；并未假定哪个词排首选，也不是按使用频率加权的动态重码率。

| 2 | 4,217 |
| 3 | 641 |

| 5 | 22 |

同码最多 7 个不同词语，共 4 组。例如 `visgi`：村子、柱子、根子、梯子、框子、菜团子、栓子。完整列表见“词与词重码.tsv”。

这两类重码词有交集，人数不可直接相加。网站按题目指定答案训练，统计反映将这些词码加入输入法时的同码候选冲突；不据此断定实际候选顺序或必须按选字键的频率。
