# 汉语字词学习顺序：每个字、每个词各计一步

本表按用户确认的目标生成：每个汉字项、每个词语项都占一个学习步骤，让高频词在完整列表中尽量靠前。词语的全部组成汉字必须先出现；已具备汉字条件的低频词可以延后。

输入实际为“现代汉语常用词表.tsv”，没有发现同名 .ts 文件。源文件未修改。完整结果包含 **5,069 个汉字引入项、56,790 个原词条，共 61,859 步**。

## 使用方法

打开 Excel 的“完整学习表”，按学习序号从上向下学习。“汉字”行介绍字形，“词语”行保留原词语及读音。单字词也单列在对应汉字行之后，例如第 1 步为汉字“的”，第 2 步为单字词“的”，以严格满足前置规则。

- 每个不同汉字只引入一次。词语、拼音、频序号逐项保留，328 条同形词额外记录不合并。
- “前置汉字学习序号”与“组成汉字”逐个对应，指向完整序列里的汉字项，不是 Excel 行号。
- “已学汉字数”只统计不同汉字；进度统计以包含字与词的总步数为准。
- “汉字顺序”表可查看每个字在完整序列中的位置。“覆盖与算法”表可查看阶段成果和候选算法。
- 汉字行的读音仅来自源表中的独立单字词；空白表示没有可直接引用的单字读音，应结合后续词语的完整拼音学习。
- 本表是固定计算结果。在 Excel 内修改内容不会自动重排，源表更新后须重跑算法。

完整字词学习表.tsv 是同一顺序的通用文本表，采用 UTF-8 BOM；完整字词学习表.txt 是逐项阅读版。所有最终结果均采用“每项一步”口径。

## 优化目标

源表只有频序号，没有真实出现次数，因此采用代理权重：

    词条权重 w_i = 1 / 原频序号 r_i
    目标 J = Σ(w_i × C_i) / Σw_i

C_i 是该词在完整字词序列中的位置。每个汉字和词语占一项；汉字没有额外词频权重，但引入新字会占用步数，并解锁依赖它的词。硬约束为：

    词中每一个不同汉字的引入位置 < 该词语的位置

J 称为“加权平均词语出现步数”，越小越好；它等价于最大化整个学习过程的加权词语覆盖曲线面积。高频词越晚出现，代价越大。这优化整体过程，不保证每个预算、每个“前 N 词”截断条件都优于其他顺序。

每项成本相同，不进一步区分笔画、词义、读音难度或复习时间。“已学覆盖”仅指词条已在学习序列中出现，不声称学习者已经掌握，也不等于自然文本覆盖率。频序倒数不是实际词频。

## 算法

1. 建立词条所需汉字、当前缺字集合以及汉字到词条的关联索引。
2. 同时比较“学一个已解锁词”和“补新字以解锁一组词”。
3. 将缺字集合相同的词分组，按词权重递减排列。设缺字集合为 S，考察组内前 k 个词，计算组合收益密度：

       D(S) = max_k [前 k 个词的权重之和 / (λ × 缺字数 + k)]

   λ=1 时，分母就是补齐新字并学习这些词的总步数。同一组新字可解锁多个词的共同收益因此被纳入考虑。
4. 若最高权重的已解锁词收益更大，就直接学词；否则从最佳组合中选一个潜在构词收益最大的汉字，学习后立即更新所有状态并重新决策，不强制整批做完。
5. 比较 7 组启发式参数以及“严格按词频逐词补齐缺字”基线。λ 只调整候选生成策略，所有结果的评价仍严格按每项一步。另以 p 调节同组内选字时的缺字数折扣。
6. 对最好的 3 个候选各做 4 轮局部精确优化：每个窗口最多 8 个字词混合项，子集动态规划在全部合法窗口内顺序中寻找最小加权出现步数，相邻轮错开 4 项。窗口外顺序保持不动。
7. 从 11 个候选结果中选取目标值最小的完整顺序。

选中方案为 **收益密度贪心 λ=1, p=2 + 字词窗口精确优化**。全程没有随机数，相同输入与参数可以复现。窗口内部求解是精确的，完整顺序仍属启发式优化，**没有全局最优证明**。候选分组只聚合同一缺字集合的词，没有穷举所有不同缺字集合的并集组合。

加权平均词语出现步数由基线的 **5,902.251** 降到 **5,781.719**，降低 **2.04%**。1,000 步时，前 1,000 词覆盖由基线的 535 个增加到 611 个；3,000 步时，前 3,000 词覆盖由 1,923 个增加到 2,135 个。

这有明确取舍：1,000 步时，前 500 词本方案已安排 463 个，基线为 500 个。本方案利用共享汉字覆盖更多其他高频词，改进整体加权目标，不以“尽早学完前 N 词的每一个”为唯一标准。

## 完整性与边界

- 56,790 个频序号连续、唯一、无遗漏；原词语、拼音与频序号完全保留。
- 5,069 个汉字各引入一次，包括单字词在内的所有词条均满足严格汉字前置。
- 字母与标点原样保留，不作为汉字前置；共有 22 个此类词条，另列于含非汉字词条.tsv，例如“阿Q”“卡拉OK”。
- 识别 Unicode 扩展区汉字、兼容汉字和“〇”；重复字只需引入一次。
- 小型测试的混合窗口动态规划与穷举全部合法排列的最优值一致；另测确定性、依赖合法性和低频已解锁词延后。
- 独立验证脚本从磁盘重算阶段覆盖与目标值，逐单元格比对 Excel 完整明细和 TSV，检查筛选与冻结窗格。

源表未另做用词、拼音或 OCR 校订，排序依赖输入质量。

## 重新生成

最终入口为 learning_order/build_step_order.py，依赖 Python 3.10 及以上标准库。在项目根目录执行：

    python learning_order/build_step_order.py
    python -m unittest discover -s learning_order -p "test_*.py" -v
    node learning_order/export_workbook.mjs
    python learning_order/verify_outputs.py

Node 导出依赖本机已配置的 @oai/artifact-tool；仅生成 TSV/TXT 不需要 Node 或其他 Python 包。--input、--output、--rank-exponent、--passes 可指定输入、输出目录、频序权重指数和局部优化轮数。Excel 导出脚本默认读取本结果目录。

build_learning_order.py 提供共享读取和汉字识别函数，并保留前期“只按汉字数计成本”的探索算法；它不是最终排序入口，请运行 build_step_order.py。
