# 潇明习字设计系统

版本：2026-10-24。该文件是本项目的视觉与交互规范；后续页面优先沿用这些语义规则。

## 设计方向

以字形为中心的练习桌。把表达集中在汉字、字根、笔画和注音，界面只提供明确的输入位置与安静的状态反馈。主体居中；课程与设置采用左对齐的阅读布局。

复核：衬线字形和极简界面符合本项目的内容与用户偏好。去掉原先易套用的巨幅空白、重复数字、小号等宽元信息和装饰性分隔；不采用技能搜索给出的营销首屏、儿童字体、亮色 CTA 或展示动画。

```text
潇明习字          练习  课程  字根  记录       简繁 主题 设置 暂停

               首笔／初识                 第 1 项

                          字形
                         读音／例根
                          拆分
                      答案（固定列）
                      输入（同列宽）
                       必要状态

               本轮次数                 查看答案／操作
```

## 基础色彩

| 语义 | 深色 | 浅色 |
| --- | --- | --- |
| 画布 | `#1E2327` | `#F3F4F1` |
| 次级表面 | `#252C30` | `#FBFCF9` |
| 主要文字 | `#ECEEE8` | `#283330` |
| 次要文字 | `#ADB7B8` | `#5A6862` |
| 操作／焦点 | `#ABCABD` | `#345E51` |
| 边界 | `#657279` | `#7C8982` |

辅助分隔线可以更低对比度，但不得用作唯一的输入边界或焦点标识。

| 编码语义 | 深色 | 浅色 | 其他标记 |
| --- | --- | --- | --- |
| 大码 | `#9BC5F2` | `#355F91` | 大写、A |
| 小码 | `#A4C8AA` | `#3E6849` | 小写、S |
| 补码 | `#DFBF88` | `#805C24` | 小写、B |

成功只用小幅反馈；订正使用补码同系的温和颜色。不可把整个练习画布染红。普通文字对比度目标 4.5:1，输入边界和焦点标识目标 3:1；分别验证两种主题。

## 字体与尺寸

- 字形、注音、字根：`Yuniversus`（仅私用字形范围）→ `Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → `SimSun` → serif。学习对象不得切换为无衬线。
- 界面：本机 Segoe UI / 苹方 / 微软雅黑；常用文字 14–16px，辅助文字 12–13px，标题 24–28px。
- 工具页主标题沿用衬线字体，正常字重；表单分组和说明使用界面字体。字根索引编码手机不小于 15px，三位间距 4px，保留原有 ASB 分色。
- 编码：Cascadia Code / Consolas，禁用连字。主编码与输入 32px 左右；小屏按列宽等比缩放，保持列中心重合。
- 大字：单字约 136px，双字词约 112px，长词按长度收敛；注音约 104px，笔画约 136px。手机字形与注音同比例缩小。
- 标题字重正常，少量界面分组可用 600。编码角色标签 12px。

## 布局与组件

- 间距使用 4 / 8 / 12 / 16 / 24 / 32 / 48px。
- 页头不超过 72px；桌面工具页宽 1080–1120px，设置与帮助正文宽约 640px。
- 页头与工具页共享左右边界；侧边距桌面 32px、平板 20px、手机 16px。导航当前项用细线和字重标识。
- 简繁切换用主题按钮旁的单个“简／繁”按钮，显示当前课程；与主题、设置共用 44px 尺寸、颜色、圆角、悬停和焦点样式。不另设下拉框，加载时禁用按钮，切换完成后回到练习输入。
- 练习列宽不超过 720px，字形—拆分—答案—输入共同居中。字形区、拆分区、编码行、输入行和状态行预留稳定空间。
- 答案列宽、输入列宽和光标底线由相同变量控制。字根完整 ASB 同行、三位全部输入，答案与输入三列等宽且逐列对齐，整组相对字根居中。回忆隐藏完整三位，Tab 提示下一位，不再单独考大码。同形同码汉字与字根共用一次练习和复习。
- 控件高度至少 44px，移动端保留安全边距。控件圆角 6px，弹窗圆角 12px；不使用统一大卡片或玻璃背景。
- 表格保留可读行高、弱化原始编号、突出内容与编码。小屏优先让非关键列退场，而不是压缩字形或缩小字体。
- 小屏课程表保留内容、编码、查看三列，序号和类型并入内容列；空结果始终可见并可直接重置筛选。基础课不保留空的拆分行。
- 字根视图提供键位索引、搜索、同语义编码色。每个字根保留官方完整编码。

## 交互状态

同页重绘保留焦点、输入选择、未保存的表单值、原生折叠区和滚动位置。弹窗打开时背景 inert，Tab 循环涵盖可见链接、按钮、表单控件及 summary，关闭后归还焦点。跳至正文入口仅在键盘聚焦时出现。

| 状态／动作 | 行为 |
| --- | --- |
| 初识 | 原提示区显示拆分与编码；输入框为空。 |
| 回忆 | 原提示区保留位置，隐藏答案；输入完成前不判错。 |
| Tab | 原编码列短暂显示下一位；不移动布局。 |
| 空输入按空格 | 记录未想起，进入订正。 |
| 输入错误 | 单次保存重来；保留错码并标记错误位置，整段选中表示下一次输入会替换，不显示尾部插入光标；原提示区展示答案。重新聚焦、点击输入或移动光标时仍明确整段替换。 |
| 订正 | 首个新字母替换整段错码，保留该字母；照打正确后继续，不重复评分、计数或解锁。退格、删除也可一次清空错码。 |
| 输入正确 | 保存后直接接续；不设置成功反馈的强制等待。 |
| 保存期间 | 正确完成后的主动字母可排队，按键重复与错误后的输入不跨题。 |
| Ctrl+Z | 回到上一道已作答题并撤销其记录，支持本次打开期间连续回溯。 |
| Esc | 暂停／继续；弹窗优先关闭。暂停后焦点落在继续按钮。 |
| 点击练习空白 | 恢复输入焦点；选择文字时不抢焦点。 |
| 路由／弹窗 | 新页聚焦标题；关闭弹窗回到触发位置；返回练习聚焦原输入。 |

字根题输入完整 ASB；所有输入接受大小写，显示按角色转换。声母、首笔映射仍作为前置，汉字／词语随后解锁。同形同码汉字保留查阅身份，与字根共享掌握状态，不另行重复出题。

### 课件与释义（v21）

- 首笔和声母以下一级的字根作示例，排除与展示笔画相同的孤立笔画；字根才以实际包含它的汉字举例。每组最多三个，按真实可用数量居中，不凑数。
- 每个注音单独对应上方的拼音标注；合组只使用小号半角斜杠，不使用全角斜杠。字根和前置提示使用“横画、竖画、撇画、点画、逆时针折画、顺时针折画”，沿用衬线小字；首笔课程的主体仍展示实际笔画。
- 无独立“规则”类型。无读音字根首次出现时说明“小码同补码”，只依赖首笔课，不把“丶”再作为规则题。
- 英文简释与就近的展开图标组成紧凑入口，按分号 ; 或点击打开阅读弹窗；读音、义项、关联词条分层。关联词条用自定义按钮与区域，保留 aria-expanded、键盘和焦点行为，不使用默认 details/summary。
- 页面、表格和弹窗共用随深浅主题变化的细滚动条；保留原生滚动，强制颜色模式使用系统颜色。
- 当前处于开发测试阶段，不做旧进度迁移或兼容。新课程使用独立开发存储，备份仅接受当前版本。
- 课程页提供搜索、筛选、查阅及面向全部筛选结果的练习；移除下载、来源和历史资料入口，词典也不展示数据包入口。资料仍在项目目录中，设置中的学习进度备份保留。

## 运动与验收

### 中英词典（v15）

- 英文只用于汉字、词语；基础映射和字根课保持聚焦。字形、注音与拼音之后放一条低于字形／编码层级的英文简释，至多两行。回忆、提示和订正时位置不变，长义项不挤动输入区。
- 简释可按分号 ; 或点按展开完整词条；关闭后恢复原输入与计时。全量词典查询入口放在暂停菜单，不占练习导航。词典条目保留原始字形，不随界面繁化。
- 简繁分别精确匹配词形，再按当前读音排序；同音优先普通义项，其他读音明确分组。区域声调差异及无匹配读音不得冒充完全一致。变体／参见提供原词及关联释义，循环引用有界。
- 英文是附带阅读，不新增评分或打断打字节奏。词典加载故障不能阻断课程。完整词典、原始压缩包、版本、哈希和 CC BY-SA 4.0 署名均保存在本地。

### 课程选词与排序（v16）

- 统计频表不直接作为全量教学清单；繁中保护分级词，其他词须有词典词头和明确词频门槛。两套课程按接近的词汇规模设计，不能以英文覆盖率作为唯一质量目标。
- “已具备组成字”只表示可以学习，词语仍须参与按学习步数和常用度排序。简繁采用同一混合字词步数目标；不在某个字后立即堆放所有已可拼出的低频词。
- 原始文件保留。当前学习位置可调整，旧项目身份和编码保持稳定；归档历史不自动出题、不进入待复习数量，但备份及记录仍可识别。

### 本地学习资料（v20）

- 用户可见类型统一为“声母、首笔、字根、汉字、词语”，由同一个模块提供给界面和导出器。单字词归入汉字，核心／扩展仅作为备注，不和类型混列。
- 导出文件仅保存在本地目录，网站不提供下载入口。学习路径含全部基础与字根，字词表只含当前字词，字根表用于查码；文件名标明简中／繁中。
- 表格中文列名和术语跟随课程语言；学习字形、注音、拼音和编码不得因界面本地化被改写。前置项目引用用户能看到的学习序号，不要求查内部 ID。
- 原始输入和历史清单保存在项目目录，不放到网页。筛选前清单明确标为历史，不冒充当前队列；原技术文件保留，独立导出用于学习查阅。

- 输入字符即时反馈；无页面入场、摇晃、缩放、闪烁、粒子或装饰性加载。
- 切换题目时，字形使用 130ms 的透明度过渡（0.7→1），从出现起就可阅读；输入区和提示编码不参与动画，布局不移动，也不等待动画结束才接收输入。该时长是本项目的节奏选择。
- 控件色彩使用约 100ms 的短过渡；所有运动尊重 reduced-motion。
- 必测桌面、小屏、窄横屏、放大文字、浅色／深色，以及回忆、Tab、订正、回溯、弹窗、备份迁移。
- 输入不被重绘丢失，字形与输入中心稳定；长词与私用字形不裁切。对比度、命中区和核心交互结果应有可复现的本地检查。

### 排版与提示复核（v25）

- 注音标题使用显式 flex 居中，拼音与注音使用独立行；禁止依赖大字号行内基线来分配高度。示例必须与完整标题盒保持间距。
- 简码与兼容字形沿用汉字的字形、读音、释义网格；固定简码不展示无关拆分，同形单根不重复展示。主练习页不显示开发核对声明或重复训练标签。
- 取码过程的序号、编码、角色垂直对齐，五位码在 320px 视口同排。确认空格只关联确认操作，不关联字根。
- 字形对照使用等高区域，代码在两栏底部对齐；缺字字体回退必须准确说明。
- 初识与纠错保留相同的输入坐标；纠错提示允许两行完整显示。预览不显示内部路径序号，帮助从暂停菜单进入。
- 完整复核记录见 [前端排版复核 v25](../../docs/前端排版复核_v25.md)。布局回归命令：`npm run test:layout`。

### 筛选结果练习（v26）

- 课程列表上方统一展示可练数量，以及「无提示自测」「自由练习」两个批量入口。范围包含全部分页；不可练项不进入队列，无可练项时禁用入口。
- 当前筛选生成固定的一组课程，按原课程顺序连续作答；不额外添加前置、不限制为当前分页。自测默认隐藏编码，自由练习始终显示编码。
- 显示已完成数与总数，答错需订正后继续。支持暂停、切换简繁后继续、Ctrl+Z 回溯，完成后可重练整组或返回原搜索、筛选和页码。
- 详情只保留明确标为「练习此项」的单项预览，两类练习均不写入正式学习卡片、日志、统计或待订正状态。查看答案仍会按原规则标记正式题的辅助回忆。
- 验证命令：`npm run test:filtered`。正式版独立目录同时纳入浏览器全套回归。

### 课程操作与视觉整合（v27）

- 依据用户指定的 [Frontend UI Engineering](https://github.com/addyosmani/agent-skills/blob/main/skills/frontend-ui-engineering/SKILL.md)，对照现有字根、设置及练习页的阅读层级，不增加新的视觉语言。
- 课程数量与两个批量操作共用表格上方一行。操作等权、使用文字按钮、保留 44px 点击高度；不再设独立说明块、实色 CTA 或额外分隔。
- 默认简中出现不可练项时，数量在左侧分两行显示，不把右侧动作挤到下一行。320px 保持并列；字体放大时允许整体换行。
- 跨分页与不计入进度的规则保留在操作帮助及可访问说明中。单页结果隐藏分页，多页结果标明当前显示范围。
- 工具页返回与练习页返回沿用轻量按钮；完成页与工具页共用衬线标题，主次动作按原样式体系呈现。
- 主题切换时按钮文字、背景同步切换，避免颜色过渡中出现低对比度。保留题目、折叠和轻提示的既有动效及减少动态效果设置。
- 已用浏览器字体面板确认：界面使用 Segoe UI／微软雅黑，标题和学习字形使用衬线字体；不为这次视觉调整替换课程字形或新增字体资源。

- 本轮验证：47 项正式版单元测试、10 组浏览器回归、1,080 组学习布局，以及简繁 34 种页面／状态 × 两主题 × 四档屏宽，共 272 组 axe 4.14.0 检查通过。批量练习另覆盖六档视口、对齐与 44px 操作区。截图及机器结果位于正式版独立目录的忽略路径 `artifacts/ui-finish/`，不纳入源码包和静态部署包。

### 学习文案复核（v28）

- 操作说明只介绍练习方法、常用按键、课程与自测、进度与备份。常用按键与实际行为对应，撤销提示随当前练习模式变化。
- 学习页面不展示资源介绍、许可及下载链接、原表序号、词库规模或实现名称。正式包中保留必要的第三方文件；不通过操作说明引出。
- 状态采用「未练过／已练过／待巩固」，台湾字形在筛选、菜单和详情中使用同一名称。参考读音只保留简短提示。
- 课程详情仅展示字形、读音、编码、取码说明、英文释义及需要先学的内容。文案不改写课程字形、注音和编码。
- 错误提示说明发生了什么及下一步操作，不展示浏览器异常或原始 JSON 内容；备份导入明确提示将替换当前简繁课程的进度。
- 课程加载失败使用外部事件处理的重新加载按钮，适用于正式版内容安全策略。原开发工作区保留导出工具所需配置；正式版清除闲置配置与说明表文件。

- 本轮检查通过：47 项正式版单元测试、10 组浏览器回归、1,080 组学习布局、272 组简繁深浅主题及屏宽的文案／可访问性检查，依赖审计 0 个已知漏洞。正式版跟踪 77 个文件，静态部署包 38 个文件；源码与部署归档均逐文件验证 SHA-256。GitHub 没有变更。
