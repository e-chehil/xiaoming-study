# 潇明习字前端体验审查

本文件保留 2026-10-23 的审查记录。最新修正与验证见 [前端排版复核 v25](前端排版复核_v25.md)。

日期：2026-10-23。范围：本地项目，不修改学习表、编码算法或 FSRS 评分语义。

## 定位

一个安静、专注、键盘优先的个人学习工具。首要任务是看清字形、回忆编码、顺畅输入。界面的个性来自汉字与注音本身，操作反馈服务于连续练习。

## 改造前的发现

| 问题 | 证据与影响 | 处理 |
| --- | --- | --- |
| 视觉任务距离偏远 | 在 1440×900 的实际浏览器中，汉字标题区 y=206.9、高 216；输入区 y=616.9。字形、拆分、编码、输入散在较长纵向距离上。 | 收拢为固定的字形区、拆分区、编码与输入区。 |
| 主次关系不够清楚 | 课程总数 59,193、每日目标、导航、路径、本轮次数、查看答案与帮助同时出现。 | 路径只显示当前项；统计与操作放在外围；保留必要的状态。 |
| 编码与输入偏小 | 字形大，答案仅 27px，角色标签仅 9px；手机路径 10px。 | 编码和输入共享列宽；角色与辅助文字不低于 12px。 |
| 字体规则分散 | 声母之前两次单独更改 font-family；笔画、字形和界面没有统一命名。 | 设定字形、界面、编码三种语义字体，并统一所有页面。 |
| 控件命中区域小 | 桌面图标 34px，手机 29px，底部帮助 28px。 | 图标和常用操作按 44px 命中区域布局。 |
| 正确后的停顿吞掉连续输入 | 正确后有固定 160ms 只读反馈；期间普通按键被 preventDefault。 | 移除正确后的展示关卡，异步保存期间仅缓存主动输入的下一题字母。 |
| 暂停与导航的焦点未管理 | 输入框每次 render 都会聚焦；暂停、列表、设置没有明确的目标焦点。 | 练习聚焦输入，暂停聚焦继续，工具页聚焦标题；弹窗关闭回到触发位置。 |
| 输入失焦后缺少恢复路径 | 点击练习区空白会离开输入，键盘事件只响应 code-input。 | 点击练习区域可恢复输入焦点；保留文本选择行为。 |
| 查表试打会覆盖原题 | 原 `startFree` 直接替换 current 并归零本轮计数，返回后原来的部分输入无法恢复。 | 临时保存原练习帧；试打结束后保留原题、输入、计数与有效用时。 |
| 原字根索引浪费空间 | 397 根分成三列大组，各组高度差异造成空白，缺少键位定位。 | 增加可键盘操作的键位索引与搜索，组内使用紧凑的等距字根单元。 |
| 次要页面仅有默认表单结构 | 列表原序、基础映射说明重复；设置缺少按任务分组；下载链接抢在列表之前。 | 统一工具页排版、任务分组、表格层级与按需下载入口。 |

实际测量中，单字回忆与订正的坐标一致，因此没有把“该状态必然跳动”列为已证实问题。新设计会进一步覆盖字根、声母、长词和移动设备。

基线截图与坐标：`artifacts/design-before/`。它们使用独立浏览器上下文生成，没有访问用户浏览器内的学习进度。

## 实施前确立的规则

完整规范见 [设计系统](../design-system/xiaoming/MASTER.md)。

1. 字形是唯一主要视觉焦点；答案与输入位于同一列网格。
2. 正常输入不逐字判错或提前透露正误，满码只评分一次。
3. 订正只负责完成输入，不覆盖首次回忆结果；空格、Tab、Ctrl+Z、Esc 的含义保持一致。
4. 正确后直接接续；存储失败必须保留可恢复状态，不把未保存的输入当作成功。
5. 不用重复提示解释程序内部实现。帮助、导出、记忆参数在用户需要时出现。
6. 先通过交互回归，再以实际截图检查字形、长词、两种主题和小屏布局。

## 实施与验证结果

已按设计系统改造练习、暂停、课程、字根、记录、设置、帮助和详情弹窗。导航与操作焦点统一；字根增加键位索引、搜索和方向键操作；词语拆分只展示参与取码的字符及字根，保留原始课程和完整拆分数据。

正确后已移除原有 160ms 的只读反馈阶段。异步保存有明确的 busy 状态，主动输入的下一题字母可以排队；保存失败不会推进，错误后的多余输入不会跨到订正题。订正仍只使用首次作答评分。

运行结果：

- `npm test`：30 项通过，包含课程依赖、角色大小写、原码一致性、FSRS、旧备份和本地服务。
- `npm run test:browser`：完整交互通过，涵盖首次学习、回忆、Tab、空格、订正、刷新恢复、Ctrl+Z、无限流、到期优先、备份和移动视口。
- `npm run test:design`：七种尺寸 × 两种主题，共 14 组布局通过。375×812、768×1024、1024×768、1440×900、844×390、375×440、720×450；包含窄屏、矮屏和横屏。输入底部均处于可视范围内，无页面横向溢出。
- 普通文字、次要文字、编码色在画布上的对比度均达到 4.5:1；最弱文字色为浅色模式 4.55:1。输入边界分别为深色 3.20:1、浅色 3.30:1。
- 编码提示与输入列中心差小于 1px；单字回忆、Tab 提示、订正的坐标一致。字根只考大码和已知 S/B 的显示保持原有语义。
- 延迟保存完成回调 200ms 后连续输入两题，顺序和记录正确；错误后同样快速输入多余字母，不带入订正。
- 暂停、页面标题、弹窗焦点往返、字根键位方向键、查表试打后恢复原题、长词和 reduced-motion 均通过。
- 本机检查的按键事件到输入 DOM 更新样本约 0.5–1.2ms；该值不包含显示器刷新、真实设备输入链路或完整端到端延迟，不作为其他机器的速度承诺。
- 学习数据 SHA-256 与生成元数据一致；本次改造未重新生成或修改学习表。

检查使用 Windows 上的独立 Edge/Chromium 上下文，视口模拟不等于实际移动设备测试。结果与截图位于 `artifacts/design-after/report.json` 和同目录 PNG。设计技能副本和检索脚本位于忽略目录 `.local/design-skills/`。

## 错码保留与切题反馈（v11）

满码输错后保留原输入，以错误色和位置标记供对照；答案仍显示在原提示区。继续键入时先替换整段错码，首个字母直接进入订正。回撤或删除可一次清空；查看提示、移动光标不会清空错码。空白查看答案仍保留空输入，刷新恢复首次提交的错码。订正不重复评分或修改首次 FSRS 结果。

切换题目时仅对题目字形应用 130ms、透明度 0.7 到 1 的过渡，输入框与编码不参与动画，不增加等待或位移。开启系统“减少动态效果”时停用。

再次运行 30 项单元检查、完整浏览器交互和 14 组布局检查均通过；新增覆盖错码保留、首次字母替换、重复订正、刷新恢复、回撤清空、原生输入事件和减少动态效果。错码对照截图：`artifacts/v11-retained-error.png`。

## 替换状态与字根居中（v12）

发现保留错码时仍有尾部插入光标，而下一字母实际会整段替换，视觉暗示与操作不符。现在保留完整原输入并整段选中；输入范围有居中的弱底色，隐藏插入光标，错误位置继续标记。点击、重新聚焦、暂停返回和刷新恢复保持这一状态；开始订正后立即恢复普通光标。

原字根编码只将大码放入居中布局，小码和补码绝对定位在右侧，详情页也复用了这一练习专用布局。现在练习中的已知 S/B 进入独立居中参考行，待考的大码继续和输入位对齐；详情页使用完整 ASB 三个等宽单元，字号和基线一致，整组相对字根居中。单字字形取消末尾字距；详情没有读音时不显示空分隔符。矮屏参考行跟随实际网格高度，避免碰到下方编码行。

交互回归覆盖单码、多码的整段替换、点击与方向键、暂停和刷新；视觉检查在原有 14 组字词布局之外增加 14 组字根布局，并检查桌面和手机的完整编码详情。截图见 `artifacts/v12-retained-error.png`、`artifacts/design-after/v12-root-*.png`。

## 完整根码恢复同行（v13）

v12 将已知 S/B 放在上方、大码放在下方，打散了完整根码，阅读顺序也变成 S/B→A。本次撤销这一排法：练习与详情均按 A→S→B 同行排列，三列等宽、同字号、同基线，整组相对字根居中。输入位正对待考的 A 列，常显 S/B 使用较轻字重；回忆和 Tab 提示只影响 A，不改变 S/B 的位置、内容和颜色。移除旧参考行留下的空位。

视觉复核包含用户反馈中的“石”（Bek），桌面与手机截图见 `artifacts/design-after/v13-stone-*.png`。原 14 组字词布局及新增的 14 组字根布局继续检查完整编码居中、同基线、输入列对齐和窄屏不溢出。

## 简繁课程与双读音（v14）

在页头加入紧凑的原生课程选择，保持 44px 操作高度；繁中课程启用繁体界面，实际学习字词、官方字根和编码不参与界面转换。输入区继续为首要交互，选择课程后恢复焦点，不增加确认页面。

字词同时显示注音与拼音，读音行可换行，字形区随实际读音高度容纳内容。注音使用现有衬线字形字体，拼音使用衬线字体；两者均与等宽编码区分。自动推读以轻量“推读”标记及来源提示说明，不冒充国教院或教育部读音。设置中移除与新要求冲突的单独拼音开关。

新增课程专项检查覆盖：原简中数据库与备份、简繁独立 FSRS/日统计/回溯/待订正状态、切换后部分输入恢复、刷新后的选择恢复、双读音和完整字根原形、繁中界面、课程对应下载和备份隔离。模拟繁中表加载失败时保留原课程与输入；后续切换成功清除过期提示。复核 375×812、320×640 与 844×390，修正 320px 下原生输入框超出视口的问题。

33 项单元检查、原交互回归、原 28 组字词/字根主题布局及双课程专项检查通过。生成的数据文件、下载表与元数据 SHA-256 已核对。截图位于 `artifacts/v14-traditional-study-*.png`。

## 中英释义与完整词典（v15）

汉字、词语的双读音下加入安静的英文简释，最多两行，不改变回忆、提示与订正间的输入位置。词典提供独立的完整义项弹窗，按 ↓ 打开、Esc 回到原输入；弹窗不展示编码，暂停回忆计时。基础映射与字根课继续只显示其学习内容。全量查询入口放入暂停菜单，页头不添加新导航。

英文区的长句采用约束宽度和缩略；小屏使用零最小宽度网格，防止长英文撑出视口；矮屏改为单行简释并收敛字形尺寸，保持原有输入空间。词典条目中的繁简对照独立于界面繁化，所有文本转义；关联词按词形和读音链接，变体引用链显示实际义项并防止循环。查询结果优先精确词头，课程中的中文检索不混入英文义项里的引用。

完整词典独立于课程与进度，分批建立本地索引。词典晚于页面就绪时只更新释义节点，不重绘输入；加载错误不阻断学习，可从词典页重试。完整原包、版本哈希、CC BY-SA 4.0 署名、课程覆盖与未匹配清单均保存在本地。

检查覆盖逐条原始数据一致性、多音／姓氏／简化合并字的义项选择、v1/v2 格式、引用链、断网恢复、键盘弹窗返回及两种字形。视觉截图为 `artifacts/v15-english-*.png`、`artifacts/v15-traditional-english-375.png`、`artifacts/v15-meaning-desktop.png` 和 `artifacts/v15-dictionary-mobile.png`。

## 繁中词库与顺序修正（v16）

核对原工作簿后，发现 v14 将完整统计词频表全量装入学习，并误用“解锁汉字数”优化，和简中实际采用的“每字、每词各计一步”算法不同。“一一一”“一一一一”虽分别在原频序 70,841、140,632，却因只需要“一”被提前到第 19、20 项。

本版保留纯汉字分级词，其他词需要精确的教育部／CC-CEDICT 词头和至少 0.2 平均每百万词频；恢复混合字词步数优化并允许低频词等待。繁中改为 56,410 项，与简中 59,193 项接近。“一一”“在在”保留真实词义，分别移到 3,285、11,353 项；“學習”移到 670 项。

旧 ID、编码与源哈希稳定；108,411 个退出队列的历史单位保留目录，旧卡、日志、日统计和备份可继续识别，归档项不进入当前待复习或待订正。新增真实浏览器检查覆盖归档卡仍可导入导出、旧待订正不会出题，以及统计和历史词形显示。完整证据见 [繁中词库审计与修正](繁中詞庫審計與修正.md)。

## 下载组织与名称（v17）

原课程页的下载入口在表格末尾，两个文件标题没有交代是否包含基础与字根；繁中“原始字词表”实际是筛选前的旧学习清单。技术表还混用英文列名、`root/stroke` 等内部类型、`core/extension` 与“汉字兼单字词”等历史标签。

现在下载区位于课程页上方，原生折叠后只显示一个入口。展开为学习路径、字词表、字根表，分别说明范围和条数；手机改为纵排，保持键盘操作和 44px 点击区域。来源与历史另折叠，繁中明确提示旧清单不代表当前顺序。

新导出按简繁分别命名，全部使用对应中文列名，编码保持 ASB 大小写；前置项目引用当前学习序号。字根表分列三种码，字词表只保留当前选词，原始文件和内部技术表不改写。界面与导出共用类型及繁中术语模块，统一为声母、首笔、规则、字根、汉字、词语。

逐行检查六份 TSV 的编码、顺序、依赖、字形、当前字词范围、来源哈希。实际浏览器验证六个文件响应、真实下载文件名、原生键盘折叠、当前／历史分组和 12 组主题／尺寸布局。截图见 `artifacts/v17-downloads-*.png`。

## 页头简繁按钮（v18）

移除品牌旁的课程下拉框，将单个“简／繁”按钮放在主题按钮前，显示当前课程。四个工具按钮共用 44×44px 尺寸、颜色、圆角及悬停／焦点样式；课程按钮采用现有衬线字体。切换过程中临时禁用，完成后恢复练习焦点，不新增常显提示。

课程专项验证通过点击、Enter、空格切换，加载中禁用及失败恢复、原课程部分输入、错码订正和独立 FSRS 状态。原 28 组字词／字根布局、词典交互及 12 组下载主题／尺寸检查均通过；人工复核桌面和 320px 页头。

## 页面层级与键盘细节（v19）

依据用户指定 Frontend UI Engineering 技能审查实际页面后，统一页头与正文边界、衬线主标题、细线导航状态；小屏课程表将序号／类型并入内容列，突出字词和编码，空结果提供重置筛选。字根三位码增大间距和手机字号，声母／首笔／规则课移除空拆分行。

同页重绘恢复焦点、输入选择、未保存表单值、折叠和滚动。弹窗隔离背景并捕获所有可见交互元素的 Tab 循环，新增仅在聚焦时显示的正文跳转。完整检查、截图与设计约定见 [前端细节优化 v19](前端细节优化_v19.md)。
