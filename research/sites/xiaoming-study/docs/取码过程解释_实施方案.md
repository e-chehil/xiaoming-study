# 取码过程解释：具体实施方案

2026-10-24 已实现本文的取码推导、码位高亮、提示解释、首错依据、辅助判定及小屏布局。另加入独立简码和台湾兼容字形训练，详见[实现记录与统一优序评估](学习优化与统一优序_v24.md)。下文保留具体教学设计。

目标是让学习者看懂“字形 → 字根 → 取哪些码 → 结果”，并能把规则迁移到没练过的字。继续沿用声母/首笔 → 完整 ASB → 汉字 → 词语的顺序；主课程正式输入仍是完整编码；简码在独立迁移训练中处理。

## 1. 字根题解释每一位的来源

以「女 Cke」为例，在初识与订正时，在现有答案附近显示一行简短推导：

| 位置 | 说明 |
| --- | --- |
| A：C | 女的大码在 C 键，需要记住字形与键位的联系 |
| S：k | 方案读音 nǚ，声母 n 映射到 k |
| B：e | 方案首笔分类为逆时针折，对应 e |

三位仍一起输入 `cke`。回忆时这行说明与答案一起隐藏；无音字根显示“小码同补码”，例如「丶 Lff」：首笔点→f，因此 S/B 都取 f。不会给官方无音根另补部首读音。

这些信息来自现有根码、`mapping` 和基础映射项目。A 的说明只陈述该根的键位，不编造可以从读音或首笔推导 A 的口诀。

## 2. 汉字题把码位与字根对应起来

以「好」为例，展开后保留完整根码，突出实际取到的位：

```text
女 Cke → 取 Ck
子 Gid → 取 Gi
两根字各取 AS → CkGi
```

`e`、`d` 仍可在完整根码中看到，但弱化显示，说明本题没有使用补码。点击或聚焦结果中的某一码，对应字根和 A/S/B 位置同步高亮；颜色继续使用现有蓝、绿、金，并辅以文字角色。

三根字用「做 WjNQj」说明“首根 AS、次根 A、末根 AS”；四根以上突出首、次、三、末根。首次遇到新取码结构时提供简短概括，随后按需展开。

## 3. 词语题解释选字、选根与截断

说明应直接对应本题，最多五个结果码位：

- 二字词：先标出两字的首末根，再按规则依次取码，最多五位；两字均为单根时是四位，例如「一人 HdVj」，不补造第五位。
- 三字词：突出第一、二字的末根，及末字的首末根。末字只有一个根时明确取 AS，避免误解为把同一个 A 重复两遍。
- 四字及以上：突出第一、二、三和最后一字的末根，其余字在说明中弱化显示。

截断位置直接在完整取码序列中标出，避免学习者误以为漏掉了小码。生成过程复用 `encodingSteps` 的 `charIndex`、`rootIndex` 和 `role`，不再独立维护另一套词码算法。

## 4. 初识、回忆、订正采用不同的信息量

| 场景 | 展示方式 | 学习判定 |
| --- | --- | --- |
| 初识 | 默认显示本题简短推导，可展开完整说明 | 保持首次认识的判定 |
| 无提示回忆 | 隐藏答案与推导；保留“取码说明”入口 | 未查看说明才能算独立回忆 |
| Tab 提示 | 继续提示下一码，同时只解释该码来自哪里 | 沿用已有提示评分 |
| 错误订正 | 先说明第一个错误码位的正确取法，可展开全部 | 沿用首次错误记录，不重复评分 |
| 自由自测 | 初始隐藏，按需查看 | 不写入正式复习计划 |

例如「好」输入 `cjgi`，订正说明为“第二码应取女的小码：n→k”。这只说明该位置的正确依据，不断言学习者一定忘了声母规则，因为实际也可能只是误按。

展开完整说明会接入已经修好的答案曝光机制；刷新、撤销、切换课程和跨标签页查阅，都不能把照着说明完成的题重新算作独立掌握。

## 5. 拆分理由须有逐字依据

现有数据可以可靠解释“按给定拆分如何取码”，但没有为每个字记录“为什么这种拆分胜过另一种”。因此分两步实现：

1. 先自动解释完整取码过程，覆盖所有支持练习的字词。
2. 再挑选少量易错、易混淆字，按[官方拆分教程](https://shurufa.app/learn/division)与当前字形口径逐字核对，补充简短对比。没有核对的字只显示标准拆分，不自动编造拆分理由。

主课程保留默认 `d`；独立字形迁移课采用官方 `dt`，把原汉字和所需字根列为先修，复习身份独立。

## 6. 布局与验收

说明使用原答案支持区，固定同一道题在初识、回忆和订正时的输入位置。熟练回忆保持简洁；手机只显示一句关键推导，完整过程按需展开；矮屏允许说明区域滚动。继续保留错码选中、首字母替换、满码自动判定和连续切题。

验收包括：

- 所有解释码位逐项对应当前实际答案，特别覆盖双单根词、三字词末字单根及多字词。
- 说明使用官方字根字形、方案读音和现有角色颜色。
- 查询说明后评分为辅助；错误后查看说明不新增日志。
- 320px、小屏横屏、深浅主题与减少动态效果下，输入和主要按钮可操作。
- 抽取未原样练过的组合字，检查学习者能否根据说明自行取码，而不只会抄写结果。
