# 示例层级与规则精简 v21

按用户反馈重新限定教学层级：首笔／声母 → 字根 → 汉字 → 词语。首笔和声母例子来自官方字根，字根例子来自官方拆分中的构字。排除与展示笔画重复的孤立笔画，只按真实可用数量居中，不用汉字冒充根，也不凑满三项。

原唯一“规则”项目教的是无读音字根 S=B，但用“丶”作题面，夹在首笔点与完整字根之间，容易让人以为又练了一遍点。取消独立规则题和对应筛选类型，说明并入无读音根初识；此类根只需先学首笔。首笔 ㇔ 的目标是补码 f，字根 丶 的目标是完整 Lff，保留这两个不同层级。基础课共 21 声母、6 首笔；简中路径 59,192 项，繁中 56,409 项。

多注音合组使用独立的注音／拼音单元：s 对 ㄙ，sh 对 ㄕ，各自居中。分隔符为小号半角 /；首笔提示改成 ㇐、㇑、㇒、㇔、㇜、㇕，名称保留在标题或无障碍描述。英文释义由分号 ; 打开，Esc 返回；方向键保留原有菜单导航功能。

页面与弹窗使用原生细滚动条和主题颜色，强制颜色模式回到系统色。保留滚动和布局稳定性，不引入模拟滚动组件。

用户明确表示仍处于测试阶段，无须旧进度衔接。删除进度迁移、旧 ASB 判定及归档卡兼容代码，使用独立开发数据库；当前备份格式只接受本版课程。未入选词的原始审计记录移到本地 archive 文件，不随运行课程加载，也不进入学习或备份。

验证包括例子来源、独立规则移除、当前备份、注音与拼音对应居中、半角分隔字号、首笔符号、分号弹窗、深浅滚动条及 320px 到桌面的练习布局。课件截图位于 `artifacts/v21-lessons/`。
