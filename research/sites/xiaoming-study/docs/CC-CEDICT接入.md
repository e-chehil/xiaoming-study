# CC-CEDICT 离线接入（v15）

## 数据范围和来源

使用 [MDBG 官方发布版](https://www.mdbg.net/chinese/dictionary?page=cedict)，不是在线查询接口或编辑中的未验证版本。当前快照为 **2026-10-23 09:11:46 UTC，共 125,310 条**。完整保留繁体词形、简体词形、原始带数字拼音、每一条义项、用法标签和关联词引用。包含全部字典条目，不限于课程交集。

原始压缩包和转换后的 JSON 均在 `dist/data/cedict/`，启动后无需访问外网。两套课程共享词典；英文数据独立于学习表，不修改题目 ID、编码、前置依赖、顺序、权威读音、学习表来源哈希或 FSRS 数据库。

来源：[CC-CEDICT](https://cc-cedict.org/)，由 MDBG 发布。当前数据许可为 **[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)**。原文件的完整署名、许可、日期保存在 `NOTICE.txt`，原始包和原文的 SHA-256 在 `metadata.json`。解析、简释与引用展开属于本地衍生视图，词典衍生数据沿用这一许可；此许可不扩大到其他独立课程数据或程序代码。此前版本曾使用其他许可，本项目以本次下载的文件头为准。

## 学习界面

- 汉字、词语在注音和拼音下方显示至多两行英文简释；长内容仅在练习区缩略，详情保留全部。基础映射和字根不加入英文。
- 练习时按 **↓**，或点英文区域，查看全部读音、完整义项和关联词。**Esc** 关闭并回到原输入。查看释义暂停计时，不揭示打字编码，不增加评分、回撤或提示次数。
- 回忆、Tab、订正使用同一个稳定英文位置。错码整段选中和接下来重输的行为保持一致；词典后台载入只更新释义区域，不重绘输入。
- 暂停菜单的「中英词典」查询全部 125,310 条，支持中文、英文和拼音，不限于已学或课程内词汇。词条支持键盘打开与关闭，引用可跟随查看，列表分页。
- 课程搜索增加英文检索。中文查询仍搜索学习对象，避免因释义中的引用而把别的词排到目标词之前。
- 词典加载失败时核心学习可继续，词典页提供重新载入。词典索引分批建立以让出主线程，持续输入不等待词典就绪。

## 匹配及其边界

1. 按当前课程精确匹配简体列或繁体列。不会为增加覆盖率而对当前词形做机械简繁替换；完整查询则可同时检索两种词形。
2. 将数字拼音转调号，规范分词空格、连接符和大小写，再按课程当前显示的读音、其他列出读音、同音节不同声调、其他读音排序。保留 ü/u 的差异，不把 `háng` 当成 `xíng`。普通义项优先于同音姓氏和仅有变体引用的条目。
3. 简释使用优先条目的前两个实义，不把量词列表或台湾读音说明作为主要翻译。只收了「variant of／see／used in」的条目会顺着引用取实际释义，保留目标词提示；详情保留原关系和完整义项。引用区分繁简及读音，优先匹配大小写以区分姓氏和普通词，处理循环与最大深度。
4. 词典与课程只有声调不同，或连音节也不相同时，练习区附上词典读音，详情明确标注差异。CC-CEDICT 不会覆盖原有国教院／教育部读音，也不把它的读音写回潇明取码资料。
5. 未收录词语没有单独英文简释。不会将若干单字释义拼成一条看似可靠的整词翻译。

## 重建和更新

在项目目录运行，使用 Python 标准库和现有 Node.js，不添加运行依赖：

```powershell
# 使用现有原始包重建，重新核对课程覆盖
npm run data:cedict

# 下载并验证最新官方发布包，再重建和统计
npm run data:cedict:update
```

构建器兼容 v1 单括号、v2 双括号及混合输入，逐行验证格式，核对原文件头的条目数；失败不覆盖原始有效压缩包。许可变更时停止构建，要求先核对新许可。更新后刷新本地页面即可，不需要迁移进度。覆盖报告、日期和条目数以重建产物为准，上表为本次快照。

## 验证

`npm test` 中的词典检查逐条比对压缩包和 JSON，验证多音、姓氏、发／髮、ü、声调、变体引用和全量查询；构建解析器另验证 v1/v2 混合及损坏输入。

`npm run test:dictionary` 使用独立 Edge 上下文验证实际英文显示、完整义项、引用跳转、部分输入／错码返回、读音及字形的简繁隔离、五种视口、无外网查询，以及模拟 503 后继续练习和重试。原键盘／FSRS、课程切换／备份与 28 组主题布局检查继续适用。
