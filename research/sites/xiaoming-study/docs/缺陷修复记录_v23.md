# 学习状态与练习缺陷修复 v23

日期：2026-10-23。对应[前次审计](潇明方案与学习体验审计_20261023.md)。本轮修改本地项目，课程内容、ID、既有全码与相对顺序保持。

## 已实施

1. **答案曝光进入评分。** 课程表、字根表、详情和相关字根查阅都会识别是否为当前题提供编码；无关查询不影响独立回忆。曝光标记在标签页刷新后保留，并向同浏览器的其他学习标签页同步。查看答案后撤销重答，也保留辅助标记。
2. **全部写入校验进度版本。** 卡片、日志、日统计、订正、设置、撤销和导入都在同一 IndexedDB 事务中比较并递增 revision。普通作答遇到并发会读取新记录后重算；过期撤销与导入不会覆盖新进度。不同页面不能覆盖或清除更新的待订正题。导出直接读取已提交数据库快照。
3. **自由练习撤销隔离。** Ctrl+Z/Cmd+Z 在自由练习中只重置自由题。保留原有照打一次返回课程的行为，新增可隐藏答案、再练一次的无提示自测。
4. **共用汉字遵循根卡等待。** 修复根卡失败等待时，practiceAlias 汉字可能被错误当作独立练习安排的问题。
5. **速度基准排除辅助输入。** 粘贴和已揭示答案的记录不再进入独立回忆速度样本；只从最近有效的40个样本计算。
6. **调度增量更新。** 缓存历史出现位置、到期时间与依赖可用状态；卡片验证状态改变时，失效相关下游缓存。撤销、导入、外部进度同步和课程切换会重建缓存。选择练习池候选时避免整池排序。
7. **校正活动文档。** 删除 v1/v2 兼容承诺与不存在的测试命令；统一完整 ASB、27项映射、当前开发数据库和当前备份口径，并注明繁中仍使用默认 `d` 拆分。

## 验证与证据

本轮验收通过：61项单元测试，核心练习、简繁课程、词典、28组练习布局、课件和数据一致性专项。数据一致性专项包含13组场景，浏览器未报告运行错误。

- 新增 `tests/answer-exposure.test.mjs`，检查关联答案识别、课程隔离、刷新持久化及存储不可用时的内存降级。
- 新增 `npm run test:integrity`，复现查表、跨标签页曝光、自由练习隔离、同时作答、过期撤销/导入和待订正保护。
- `tests/continuous.test.mjs` 新增辅助速度样本排除、300步增量缓存一致性及共用先修失效检查。
- 与优化前快照比较了300组静态调度场景；大规模比较包含5万张卡片与20万条历史。合成场景耗时随并发测试负载变化，优化前约127–159ms，优化后约31–43ms；不代表所有用户设备的实际延迟。

详细浏览器结果位于 `artifacts/fixes-20261023/integrity.json`，性能结果位于同目录 `scheduler-scale.json`，自测小屏截图为 `self-test-320.png`。
