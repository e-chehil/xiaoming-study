# 简繁课程与统一优序

2026-10-24，v24 当前说明。两套课程共用完整前置依赖图优序、取码解释、自动评分、连续出题和 FSRS。原先字根插入权重不同的问题已经解决；实现、指标及取舍见[学习优化与统一优序](学习优化与统一优序_v24.md)。

## 数据来源与教学范围

简中主课程保留原学习表 58,768 个字词的稳定身份。频序按当前本地 GitHub 复核词表，通过字词与原读音精确对应，五个历史频序差异已更新，来源副本和哈希单独记录为 frequencySource。原身份清单文件保留原样。

繁中来自用户提供的国教院 14,452 条分级记录与 163,701 条通用词频记录。保留可直接练习的纯汉字分级词形；其他词形须有教育部或 CC-CEDICT 精确繁体词头，平均每百万词频至少为 0.2。阈值是项目教学取舍；108,411 个未选历史单位归档，不在当前队列。

主课程之外，简中有 720 项、繁中有 535 项简码迁移课；繁中另有 455 项台湾兼容字形课。它们使用独立稳定 ID，先修引用主课程，复用进度数据库中的卡片、日志和 FSRS。

## 同一个完整图算法

两套均调用 scripts/curriculum_order.py，词条权重为频序倒数，所有需要独立练习的映射、字根、汉字、词语各计一单位，共用练习只计一次。比较旧路径、频序补齐前置与四组完整依赖图密度候选，对较好的两项做 8 项窗口、4 遍精确动态规划，按同一目标选优。

两套当前均选中 p=1.0 密度加局部优化。原简中 log(sourceId) 字根权重与繁中 1/rank 插入策略只作为历史路径的组成部分，不再分别决定最终课序。新算法没有简繁分支，候选集合、成本、别名处理和选优条件相同。

以完整路径的同一口径复算，简中加权练习位置改善 0.7629%，繁中改善 0.8394%；两套累计按键和已测早期权重覆盖也改善。个别词可能延后，详见完整报告。指标不是实际语言覆盖率或真人学习分钟，也没有全局最优证明。

## 取码、字形与读音

主课程使用官方 d 拆分；字形迁移课使用有来源的 dt，采用离线台湾区域字体并并列展示默认/兼容取法。兼容拆分不改变主课程旧答案，新增课的复习身份独立。简码来自固定官方分配表，按字形精确匹配，不进行简繁猜测转换。

繁中读音优先国教院，其次教育部《重編國語辭典修訂本》20260929 版，剩余保留推读标记。主课程国教院 14,733 项、教育部 32,043 项、推读 9,209 项；另有 222 个方案注音根、175 个无音根。简中原拼音保留，2,195 项插入字的自动推读明确标记。取码解释使用方案字根读音，不把通用推读当作根码依据。

界面使用 OpenCC 和用语映射；学习字、字根、编码和说明中的源字符均不参与繁化。词典仍使用完整 CC-CEDICT，不拼凑未收录词义。

## 存储、构建与复核

两套分别使用 xiaoming-study-dev-v5 与其 -traditional 数据库。当前 v3 备份绑定课程、源身份表和 root-foundations-v5，支持新迁移 ID，并校验卡片答案版本。原有字根和字词的答案、ID 保留；课序更新无需重置原进度。

运行加载 learning-runtime.json，共享重复汉字拆分；learning.json 是完整数据。course.schema.json、runtime.schema.json 与 scripts/validate_curricula.mjs 共同检查格式、官方来源、前置语义、取码、指标、导出和字体。

执行 npm run data:build 统一构建并校验；npm run data:validate 单独复核；python scripts/assess_curricula.py 复算评估和编码不变证明。源材料重建入口最终也调用统一构建器。

本地当前下载表在各课程 exports 目录；新增简码与字形训练表单列。outputs/traditional_learning_order_20261023 中的旧路径和算法报告为历史快照，当前结果位于 artifacts/learning-v6-20261024。
