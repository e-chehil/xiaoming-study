# 潇明习字：映射、完整 ASB 与字词取码

核对日期：2026-10-23。依据[官方方案说明](https://shurufa.app/ime/xiaoming)、此前下载的官方 397 行字根表，以及官网指定的固定 GitHub 版本。官网文字规则本次可读取；CSV 直连本次返回 403，因此没有把本地表冒充为重新下载的最新版。

## 为什么不再直接背 ASB

字根的三个位置承担不同任务。A 是需要建立字形与键位联系的大码；S 通常能从官方注音推导；B 能从首笔类别推导。把三者作为一个任意字符串同时记忆，会重复消耗记忆负担。

当前流程为：声母与首笔的映射 → 完整字根 ASB → 汉字取码 → 词语取码。无注音字根的“小码与补码相同”并入字根初识说明，不单设规则课。

每项映射单独保存 FSRS 状态。首次照着输入只算认识；需要无提示正确回忆后，才解锁依赖它的下一层。不能仅完成同一个键的一题，就把映射到这个键的全部声母都算作掌握。

## 27 项映射基础

声母按 21 个独立项目学习。z/zh、c/ch、s/sh 分别合为一项，因为方案取的是拼音首字母。

| 小码 | 对应声母 |
| --- | --- |
| d | 零声母、ㄏ、ㄧ／ㄩ |
| e | ㄅ、ㄙ／ㄕ、ㄨ |
| f | ㄉ、ㄍ、ㄊ |
| i | ㄈ、ㄇ、ㄗ／ㄓ |
| j | ㄌ、ㄆ、ㄑ、ㄖ、ㄒ |
| k | ㄘ／ㄔ、ㄐ、ㄎ、ㄋ |

声母题的题面、例子、课程列表、前置名称及下载表以注音符号展示，与答案区的键盘字母分开。汉语拼音 y 类显示为「ㄧ／ㄩ」，w 类显示为「ㄨ」，保留原方案的键位分类；不能按语言学上的零声母重新归类。官方注音以 a/e/o 等元音开头的项目进入零声母项；397 根中的实际例子为儿、而、耳、二及相关字形。根与字词已有的完整拼音仍按源表保存。[注音符号规范](https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html)、[注音与汉语拼音对照](https://language.moe.gov.tw/001/Upload/FileUpload/3692-16962/Documents/pinyinshouce.pdf)

首笔分成六项，折笔还要分方向：

| 补码 | 首笔类别 | 官方码表中的代表 | 根数 |
| --- | --- | --- | ---: |
| k | 横 | 一 Hdk、木 Vik | 97 |
| i | 竖 | 丨 Tii、日 Gji | 71 |
| j | 撇 | 丿 Sjj、白 Oej | 105 |
| f | 点 | 丶 Lff、宀 Lff | 50 |
| e | 逆时针折 | 女 Cke、厶 Lee、幺 Qde | 25 |
| d | 顺时针折 | 乙 Udd、又 Ydd、子 Gid | 49 |

页面采用 Unicode 汉字笔画字符：横㇐、竖㇑、撇㇒、点㇔、逆时针折代表㇜（撇折）、顺时针折代表㇕（横折），配合类别名称和实际字根例子。它们由系统字体绘制，没有额外下载笔画图片；折笔字符是类别的代表，并不表示这一类只有这一种笔形。之前的箭头来自项目自行绘制的 SVG 方向示意，并非官方素材，现已移除。

类别仍来源于官方完整码第三位，没有用字形识别或 Unicode 字形猜笔顺。[固定版本笔画分类约束](https://raw.githubusercontent.com/Dieken/code_genie/55e783c3973b125d3f56baac534b796c76df87a5/moling/xiaoming-output/output-20261011-061440/source/input-fixed.txt)

无注音字根的小码取补码。例如官方表中“丶”没有注音，首笔点对应 f，因此完整根码为 Lff。该说明在无音根初识时出现，无音根只依赖对应首笔。

## 字根练习完整三位 ASB

有注音根需要先掌握自己的声母项、首笔项；无注音根需要先掌握自己的首笔项。

- 学白：先掌握 ㄅ → e、撇 → j；之后输入完整 Oej。
- 学丶：先掌握点 → f；初识说明小码同补码，输入完整 Lff。
- 学女：先掌握 ㄋ → k、逆时针折 → e；之后输入完整 Cke。

首次展示完整三位，之后隐藏三位，提示按码位显示。大码大写、小码与补码小写，输入不区分大小写。同形同码汉字通过 practiceAlias 与根共用练习和复习；原汉字身份保留供查阅及词语依赖引用。

首次输入满码即判定；错误或空输入按空格查看答案，立即以重来保存 FSRS。答案展示在原提示区，错码保留在输入框并标记错误位置；继续输入第一个字母时替换旧错码，并保留这个新字母，照打正确再继续。空输入查看答案时输入框为空，没有错误后的自动切题倒计时。订正中的错码同样保留，可以重新照打，但不再产生复习记录，不改变原来的重来评分，也不能解锁先修条件。订正等待和照打时间不参与回忆速度统计。未完成的订正与首次错误记录一起保存，刷新后恢复原错码。

Tab 仍是短暂提示下一码，空格替代原先需要 Shift 的问号键。Ctrl+Z 可逐题回溯本次打开期间的作答，并撤销该次日志、FSRS 卡片变化和日统计；在订正阶段按下，则回到当前题的首次作答。导入备份清空旧回溯历史。

显示采用 A 大写、S/B 小写，例如 Lff、Oej、CkGi、WjNQj。输入不区分大小写，程序按角色调整显示，不要求按 Shift。

## 优序如何生成

两套课程现共用完整前置依赖图：所有独立练习的映射、字根、汉字和词语计入成本，同码根和字共用一次练习；词频序号倒数作为收益权重。比较频序补齐、四组闭包密度候选与历史路径，对较好的两项做 8 项窗口、4 遍局部精确优化。所有前置按最终位置与实际拆分验证，原 ID 和答案保留，字词位置允许调整。

主路径与迁移训练池都保留原有到期优先、掌握门槛和无限流。说明、简码及字形训练已实装，指标与取舍见[当前实现记录](学习优化与统一优序_v24.md)。

首次照打不解锁下一层。额外的独立正确回忆可解锁依赖，但不会推迟原 FSRS 到期时间或增加正式复习次数；回忆失败、使用提示则安排重学。非常小的已学练习池没有可回忆项时，显示答案做熟悉练习，不把照打算作掌握。

简中为 21 项声母、6 项首笔、397 项字根、5,069 个汉字、53,699 个词语，共 59,192 项。170 个同形同码汉字共用根练习；22 条含符号内容保留并标记暂不可练。繁中共 56,409 项，其中 173 个汉字共用根练习。

## 全码和简码的边界

当前字词课程继续练全码，不改变已有汉字、词组编码：

| 内容 | 取码位置 |
| --- | --- |
| 单根字 | ASB |
| 双根字 | AS + AS |
| 三根字 | AS + A + AS |
| 四根及以上 | 首 AS、次 A、三 A、末 A |
| 二字词 | 首字首末根、次字首末根，最多五位，双单根词为四位 |
| 三字词 | 首字末根 AS、次字末根 A、末字首末根 A/A；末字单根时取 AS |
| 四字及以上词 | 首字末根 AS、次字末根 A、三字末根 A、末字末根 A |

官网另有六个一键直接上屏简字、一码加空格简字、两键简字及三键简码。当前提供独立简码训练，先学对应完整取码，再按真实上屏键练习；固定一键和二、三码自动完成，一码加空格须实际按空格。[官方完整规则](https://shurufa.app/ime/xiaoming)

## 审计中避免的错误

- 本地 222 个有注音根全部符合声母映射；175 个无注音根全部符合 S=B。
- 43 个有注音根也恰好 S=B，例如目 Aii。因此用“第二位等于第三位”判断无音会造成错误。
- 勹、罒、宀、彳等即使在通用字典中能找到部首名称，也不能擅自补读音。以官方 CSV 的注音字段为准。
- 車取 chē、長/长取 cháng、糸取 sī；不接通用拼音库覆盖方案指定读音。
- 户 Hdf、戶 Hdj、戸 Hdk 的大码、小码相同，首笔不同导致补码不同。
- 形近根可以共享 A，但不能因此合并其完整 ASB。大码共有 19 个键，某个键上的全部根也不等于一个形近家族。
- 上游旧准备脚本的映射表是优化输入的一部分，不代替最终 CSV 的键位。[官方生成脚本](https://raw.githubusercontent.com/Dieken/code_genie/55e783c3973b125d3f56baac534b796c76df87a5/moling/xiaoming-output/output-20261011-061440/source/prepare-inputs.sh)

原字词 ID 1–58,768、字根 ID 58,769–59,165 保留，27 项映射使用 59,166–59,192；旧独立规则项已移除。当前使用独立开发数据库 `xiaoming-study-dev-v5`，繁中加 `-traditional` 后缀。仅接受当前课程及学习表的 v3、root-foundations-v5 备份，不承接旧版进度。

完整表为 `dist/data/声母首笔字根字词学习表.tsv`，旧三层表仅作比较基准。字词编码与原表保持一致；原始 TSV 的 SHA-256 不变。根的 `code` 和 `fullCode` 均为完整三位 ASB。

查到当前题或其取码字根的编码后，该次正式作答按辅助回忆处理；本标签页刷新、简繁切换和自由练习返回保留曝光状态。看过答案后撤销重答仍保留辅助标记。自由练习可照打一次，或通过“无提示自测”隐藏答案反复练习，均不更改正式进度。

每次正式写入在同一 IndexedDB 事务中校验并递增 revision。作答冲突会按最新状态重新计算；过期撤销、订正和导入不会覆盖新记录。切换回课程时仅恢复与数据库版本匹配的临时题目状态。

`scripts/mapping_curriculum.py` 维护经过核对的映射及先修关系，`scripts/prepare_data.py` 可重建所有运行数据。数据、规则和界面均在本地运行。
