# 潇明习字

潇明输入法的简繁学习网站，当前版本 **1.1.1**。

[在线学习](https://e-chehil.github.io/xiaoming-study/) · [GitHub 仓库](https://github.com/e-chehil/xiaoming-study)

从声母与首笔映射开始，学习字根完整 ASB，再逐步学习汉字和词语。支持逐位取码说明、简码训练、台湾兼容字形对照、中英词典与间隔复习。无需账号，进度保存在浏览器中。

## 使用

需要 Node.js 22 或更新版本。克隆仓库后运行 `npm start`，或在 Windows 双击 `start.cmd`。默认地址为 http://127.0.0.1:47831；启动本地网站无需安装开发依赖。

部署到静态托管时运行 `npm ci --ignore-scripts`、`npm run check`、`npm run build`，上传生成的 `dist/`。GitHub Pages 工作流及配置见 [部署说明](docs/deployment.md)。不要直接双击 HTML 文件。

## 练习与进度

- 初识时显示编码，随后隐藏；输入满码自动判定。大码大写，小码与补码小写，输入接受大小写。
- Tab 提示下一码；空输入时按空格查看答案；一码简字输入字母后须加空格。Esc 暂停，Ctrl+Z／Cmd+Z 撤销上一题。
- 答错后照着答案订正，首次作答只评分一次。查看答案和取码说明后按辅助回忆记录。
- 暂停菜单可切换完整取码、简码与台湾字形训练。简繁课程分别保存进度。
- 课程页可搜索并按类型、学习状态筛选；“自由练习”和“无提示自测”覆盖全部匹配项（包含其他分页），自动排除暂不可练项，不写入学习进度。完成后可重练整组或返回原筛选列表。
- 设置中可导出、导入 JSON 备份。换浏览器、清理站点数据或从本地迁移到线上前，请先导出；不同网站地址不会自动共享进度。
- 首次访问自动下载所选完整课程，并验证后保存在浏览器；之后优先读取本地，不等待联网检查。基础页面准备完成后支持断网重开；词典按需下载、长期缓存。没有账号、统计追踪或云同步。

操作说明仅介绍练习、快捷键、自测和进度备份。课程、来源、读音边界及优序方法见 [数据说明](docs/data.md)。第三方资料分别适用原许可，见 [第三方声明](public/vendor/THIRD_PARTY_NOTICES.md)；本仓库未为这些资料授予统一的 MIT 许可。

## 开发与验证

```sh
npm ci --ignore-scripts
npm run check
npx playwright-core install --with-deps chromium
npm run test:browser
```

Windows 默认可使用系统 Edge；也可通过 `EDGE_PATH` 指定浏览器。浏览器测试会启动并关闭自己的临时预览服务，使用隔离上下文，不读取个人浏览器进度。测试截图仅写入忽略的 `artifacts/`。

```text
public/          可独立部署的网站、课程、词典、字体及许可
scripts/         本地服务、白名单校验、构建与数据工具
tests/          核心逻辑及浏览器回归测试
data/           独立复核优序所需的最小频序输入
docs/           数据和部署说明
.github/         自动检查与可选 Pages 部署
```

`release-files.json` 是允许发布的明确文件清单及 SHA-256。修改现有文件后运行 `npm run manifest` 更新摘要；增加文件须先明确加入清单。检查会拒绝未登记文件、软链接、个人工作区路径及常见凭证。构建只复制 `public/`，不包含测试、研究档案、截图、依赖目录或个人进度。

完整课程本地优先、多源配置、离线更新与验收边界见 [离线与资源加载](docs/offline.md)。
